# 近景人物建模规格

更新：2026-11-24（D2）。适用于「桥畔茶铺」网页试玩中的程序化人物（`viewer/bridge-people.js`、`viewer/bridge-hands.js`、`viewer/bridge-gait.js`）。检视页：[人物检视台](../viewer/characters.html)。任务规格见[任务设计](quest-design.md)。

**目标是让一名角色在 2 米内近看时，从正面、侧面和背面都能认出身份，动作和手部不出戏，同时让远景居民可以成批合并绘制。** 风格向清院本人物靠拢：衣着轮廓清楚、色块平和、线条感来自衣缘和绑带，不追求写实皮肤。

## v1.17 近景头像

近景头部以 MakeHuman 的 CC0 基础网格和选定形变数据为底，裁出头颈后重新配色、调整各角色轮廓，并加上眼球、眼睑、唇缝和可动下颌。公开试玩保留原来的衣装、任务和关节手。街上居民按画面中的大小切换近景头部和远景低模。人物检视台可以逐个选择角色，手动调整眨眼和开口。

[固定版本的网格来源](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data/3dobjs/base.obj) · [MakeHuman 资产许可](https://static.makehumancommunity.org/about/license.html) · [生成脚本](../tools/build_character_heads.py)

## v1.26 柜台表演

交货后按 E 可请掌柜斟茶。掌柜用原角色的关节手抓壶把，手腕跟随壶把的位置和方向。抬壶前先伸手，弯肘时修正袖子的截面，鞋底在整个动作中固定在摊内地面。近景斗笠增加了竹篾交织纹。玩家和伙计的袍摆会随动作摆动，并局部让开抬高的腿。

掌柜、伙计、摊主和采买客的台词配有普通话音节节奏，驱动张口、圆唇和展唇形变。字幕在画面底部，人物检视台提供三种可手动调节的嘴型。

## 角色部件

| 部位 | 实现 | 已知问题 |
| --- | --- | --- |
| 体型 | 玩家、掌柜、伙计三套专用配色；居民四套体型（肩宽、袍摆、袖长、肤色、围裙） | 体型差异主要在衣摆和肩宽，脸型差异小 |
| 腿与步态 | 两段式 IK 腿，脚底按地面坡度贴合，重心转移与膝部蒙皮；涉水时有湿痕 | 掌柜固定在柜台内，可独立转动上身 |
| 手 | **D2 新增关节手**：手掌、拇指根垫、四指各三节、拇指三节，单一握持参数 0–1 控制全部关节；背货时自动握住背带；手臂外展约 6°，让手垂在袍摆之外 | 手指为胶囊拼接，关节处有细小接缝 |
| 脸 | 雕刻头骨、鼻梁、眼窝、嘴形，顶点色画眉和胡须 | 四套居民脸型相近，侧面识别度依赖帽子 |
| 衣物 | 车削（Lathe）袍身，按角度和高度加褶；衣襟、袖口、绑腿、围裙为独立几何 | 褶皱是几何起伏，没有法线细节；袖口与手腕交界在大幅摆臂时可见缝隙 |
| LOD | `lowDetail` 降低分段数，手指改为单节，去掉缝线；远景居民合并为每材质一个网格 | 中景到远景切换无过渡 |

## 规格

| 项 | 要求 | 验收方法 |
| --- | --- | --- |
| 比例 | 全身约 7 头身；手长（腕到中指尖）约为身高的 0.10–0.11；脚长约 0.15 | 检视台正面截图量比例 |
| 手 | 至少 15 个可转动的指节；握持参数驱动；背货、递物、斟茶三种握姿共用一套骨架；手指不投射阴影以省绘制 | 检视台「手部特写」0 与 1 两档截图；背货录像中手不穿过背带 |
| 识别 | 每名主要角色在正面、侧面、背面有一个可辨的特征（帽、围裙、配色或发髻） | 三视图盲认：给另一人看背面截图，能说出是谁 |
| 表演 | 掌柜完成一次看向玩家、说话、递物的连续动作 | 录像 |
| 性能 | 主要角色每人 ≤ 160 个网格对象；远景居民合并后每材质 1 次绘制；新增人物细节不使 4K 机位 P95 帧间隔超过 16.8 ms 基线 | `tools/profile_bridge.py` 前后对比 |
| 风格 | 不使用照片皮肤贴图；颜色取自清院本人物常见的米白、灰青、赭石、草绿 | 与原画同人物并排截图 |

## 下一步（按优先级）

1. **四套居民的脸型参数化**：颧骨宽、下颌长、眉弓高三个参数，侧面轮廓可区分。
2. **衣褶法线**：在车削袍身上叠加按褶位生成的法线贴图，减少几何分段。
3. **柜台内短距离走位**，增加转身和移动时的重心转移。
4. **中景过渡**：在 8–14 米之间交叉淡入近景与低模，避免切换跳变。
